# With a coding agent

Once a coding agent has the first version of an app on screen, the rest is
refining what works and fixing what behaves wrong, and both are hard to put
into chat. These pages move that work onto the running app itself. They
assume you already work with a coding agent such as Claude Code or GitHub
Copilot.

| If you want to… | Read |
| --- | --- |
| Get the dev extra, the skills and the MCP server in place, and your app running under the dev runner | [Set up](setup.md) |
| See every save rebuild the running window, with state and breakpoints intact | [Hot Reload](hot_reload.md) |
| Tell the agent what to change, or what went wrong, from the app's own screen | [Comment mode](comment_mode.md) |
| Fix a size, an order, a spacing or a style yourself, on the screen | [Layout edit mode](layout_edit_mode.md) |
| Read or edit the code behind a widget | [Source jump](source_jump.md) |
| Know what each skill does for you | [The skills](skills.md) |
| Let the agent see, drive and check the running app, or drive it yourself from a terminal | [The dev bridge](dev_bridge.md) |
