# Tabs MD3 Specs

Source: <https://m3.material.io/components/tabs/specs>
Collected: 2026-05-26

## Summary

- Tabs exposes two active token sets in the live viewer: `Tabs - Primary navigation` and `Tabs - Secondary navigation`, both under the `Default, Light` context.
- Both variants use equal-width tab sections, square containers on `md.sys.shape.corner.none`, 48dp label-only height, 64dp icon-plus-label height, a 1dp divider, and 24dp icons.
- Primary tabs drive the active indicator, active label, and active icon from `md.sys.color.primary`, while inactive label and icon treatments stay on `md.sys.color.on-surface-variant`.
- Secondary tabs keep the active indicator on `md.sys.color.primary`, but active label and icon treatments stay on `md.sys.color.on-surface`; inactive label and icon treatments remain on `md.sys.color.on-surface-variant`.
- Both variants share `md.sys.typescale.title-small` for tab labels, use hover opacity `0.08`, focus and pressed opacity `0.1`, and expose a secondary-colored focus indicator with 3dp thickness and a -3dp inner offset.

## Implementation Notes

- Implement both tab variants as square-corner containers with equal-width slots, a 1dp internal divider, and 48dp or 64dp heights depending on whether the tab shows only text or both icon and label.
- Reuse `md.sys.typescale.title-small` for tab labels in both variants; the extracted component rows resolve to 14pt size, 20pt line height, 500 weight, and 0.1pt tracking.
- Keep the primary-tab active indicator, active icon, and active label on `md.sys.color.primary`, but keep inactive icon and label treatments on `md.sys.color.on-surface-variant` and inactive hover or focus overlays on `md.sys.color.on-surface`.
- Keep the secondary-tab active indicator on `md.sys.color.primary` while leaving the active icon and active label on `md.sys.color.on-surface`; inactive label and icon treatments still use `md.sys.color.on-surface-variant`.
- Model the focus affordance with `md.comp.*.focus.indicator.*`: both variants resolve to `md.sys.color.secondary`, 3dp thickness, and a -3dp inner offset, while hover uses `0.08` opacity and focus or pressed uses `0.1` opacity.
