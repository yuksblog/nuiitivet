# Navigation Bar MD3 Specs

Source: <https://m3.material.io/components/navigation-bar/specs>
Collected: 2026-05-26

## Summary

- The current flexible navigation bar spec exposes three active token sets: `Nav bar - Common`, `Nav bar - Item - Vertical`, and `Nav bar - Item - Horizontal`.
- The shared flexible bar uses a `surface-container` container color, 3dp container elevation, a square container shape, 24dp icons, and a fully rounded active indicator.
- Compact-window navigation uses vertical items with a `56x32dp` active indicator, `6dp` top and bottom padding, and a `4dp` icon-label gap; medium-window navigation switches to horizontal items with a `40dp` active indicator and fixed-width item slots.
- The baseline navigation bar remains documented as a legacy section: it is `80dp` tall, keeps a `64x32dp` active indicator, and adds focus-indicator plus deprecated badge rows that do not appear in the current flexible viewer.

## Implementation Notes

- Prefer the flexible navigation bar for new work. The spec explicitly marks the baseline navigation bar as no longer recommended.
- Compact-window implementations should use the vertical item metrics, while medium-window implementations should switch to the horizontal item metrics and fixed-width item slots.
- The flexible bar container is square (`md.sys.shape.corner.none`) while both the current and baseline active indicators remain fully rounded (`md.sys.shape.corner.full`).
- The flexible viewer does not expose badge tokens; when badges are implemented on the current navigation bar, use the dedicated badge spec for badge-specific color behavior.
- The vertical and horizontal label-text rows expose only a preview in the viewer, so the implementation-relevant typography should be taken from the shared `md.sys.typescale.label-medium` source token.
