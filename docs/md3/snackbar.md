# Snackbar MD3 Specs

Source: <https://m3.material.io/components/snackbar/specs>
Collected: 2026-05-26

## Summary

- Snackbar exposes one live component token set, `Snackbars`, and the visible spec context is `Default, Light`.
- The enabled snackbar uses inverse roles: `inverse-surface` for the container, `inverse-on-surface` for supporting text and the optional icon, and `inverse-primary` for the action label.
- Geometry is compact and fixed: the single-line container is `48dp` tall, the two-line container token is `68dp`, the container shape is extra-small rounding, and the container elevation resolves to `6dp`.
- The measurement figure shows `16dp` leading content padding, `8dp` trailing padding after the action, and a close affordance built from a `24dp` icon with `12dp` padding on both sides.

## Implementation Notes

- Treat snackbars as inverse surfaces rather than standard surface containers: container fill uses `inverse-surface`, action emphasis uses `inverse-primary`, and supporting or close-affordance content uses `inverse-on-surface`.
- The component exposes two explicit height variants, `48dp` for single-line and `68dp` for two-line content, so layout code should switch variants instead of stretching a single base geometry.
- Action typography maps cleanly to `label-large`, while supporting text maps to `body-medium`; that is enough to derive the preview-only `*.type` rows without custom typography tokens.
- The optional close affordance fits a `48dp` wide touch target when the figure's `12dp + 24dp + 12dp` spacing is applied.
