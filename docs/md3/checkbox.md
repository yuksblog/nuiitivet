# Checkbox MD3 Specs

Source: <https://m3.material.io/components/checkbox/specs>
Collected: 2026-05-25

## Summary

- Checkbox exposes one active token set in the live viewer: `Checkbox` with `Default, Light` context chips.
- The checkbox box is an 18dp square with a 2dp corner shape, an 18dp icon, a 40dp state layer, and a 48dp touch target.
- Enabled selected checkboxes use `md.sys.color.primary` for the container and `md.sys.color.on-primary` for the icon, while enabled unselected checkboxes use a 2dp `md.sys.color.on-surface-variant` outline and `md.sys.color.on-surface` icon.
- Error treatments swap the selected container and unselected error outline to `md.sys.color.error`, and selected error icons use `md.sys.color.on-error`.
- Hover and focus reuse the same 0.08 and 0.1 state-layer opacity ladder from the system state tokens, while focus adds a 3dp secondary focus ring with a 2dp outer offset.
- Disabled checkboxes fade at 0.38 opacity and keep distinct selected and unselected icon opacity tokens in addition to the container opacity tokens.

## Implementation Notes

- Treat the checkbox box itself as an 18dp control inside a larger 48dp tap target; the state layer is smaller than the touch target at 40dp.
- Use a real 2dp corner radius for the box even though the token viewer renders the shape cell visually instead of printing a numeric value inline.
- Enabled and hovered selected containers stay on `md.sys.color.primary`; selected icons stay on `md.sys.color.on-primary`, while error-selected icons switch to `md.sys.color.on-error`.
- Unselected outlines start on `md.sys.color.on-surface-variant` when enabled, but interaction states promote the unselected outline and icon color to `md.sys.color.on-surface`.
- Focus adds the shared MD3 focus ring treatment: `md.sys.color.secondary`, 3dp thickness, and 2dp outer offset.
- Disabled checkbox rendering is slightly non-obvious in the live viewer because it exposes both `selected.disabled.*` and `disabled.selected.*` icon tokens; preserve both token families if the implementation models the disabled selected icon treatment explicitly.
