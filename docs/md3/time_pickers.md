# Time Pickers MD3 Specs

Source: <https://m3.material.io/components/time-pickers/specs>
Collected: 2026-03-12

## Summary

- The primary token viewer exposes two non-deprecated token sets: `Time picker - Dial` and `Time picker - Input`.
- Dial tokens define a `256dp` clock dial with a `48dp` selector handle, `8dp` selector center, `2dp` selector track, and `96dp x 80dp` time-selector cells; the horizontal period selector expands to `216dp x 38dp`.
- Input tokens define dynamic outer container sizing with `96dp x 72dp` time-input fields and a `52dp x 72dp` period selector.
- Both variants resolve their outer container elevation through `md.sys.elevation.level3`; the outer containers use `28dp` extra-large rounding while selector and input subcontainers resolve to `8dp` small-corner shapes.
- Hover state-layer opacity is `0.08`; focus and pressed state-layer opacity are `0.1` across the exposed interactive tokens.

## Implementation Notes

- Treat dial and input variants as separate widget implementations. The dial variant adds dedicated clock-dial geometry, selector center, selector track, and selector-handle tokens, while the input variant adds focused-container and focus-indicator tokens.
- Shape and elevation rows are not fully exposed inline in the viewer. The detail popups resolve them through system tokens such as `md.sys.shape.corner.extra-large`, `md.sys.shape.corner.small`, `md.sys.shape.corner.full`, and `md.sys.elevation.level3`.
- Typography `.type` rows are composite preview tokens. The viewer also exposes scalar font, size, line-height, weight, and tracking rows, which are the more direct implementation inputs.
- The dial token set includes `*.ignore` clock-dial tokens marked with a warning badge. Keep them out of default implementation paths unless you intentionally need to mirror the source exactly.
- The accessible Measurements tables for vertical and horizontal dial layouts currently expose the same numeric rows in the live DOM, so the page does not provide different orientation-specific numeric callouts beyond the shared table values.
