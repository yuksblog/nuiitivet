# Sliders MD3 Specs

Source: <https://m3.material.io/components/sliders/specs>
Collected: 2026-05-26

## Summary

- Sliders expose six active token sets in the live viewer: one common `Slider` set plus five expressive size sets from `Slider - Size - Xsmall` through `Slider - Size - Xlarge`.
- The common set fixes the baseline active and inactive track height at 16dp, the standard handle at 44dp tall and 4dp wide, and the enabled active color on `md.ref.palette.primary40` (`#6750A4`).
- Expressive size sets scale track geometry from 16dp to 96dp and add inset-icon tokens from medium upward: medium and large use 24dp icons, while xlarge uses 32dp icons.
- Disabled states mute the slider onto neutral tokens with 0.38 active-track and handle opacity and 0.12 inactive-track opacity.
- The measurements chart and token viewer disagree on a few geometry values, notably the medium handle height and the label container height; the discrepancy is documented below instead of being flattened away.

## Implementation Notes

- Treat sliders as a common behavior surface plus expressive size overlays: the `Slider` token set owns state colors, stop indicators, value indicator styling, and default track or handle behavior, while the size sets only patch the geometry.
- The enabled common slider uses `primary40` for the active track and handle, `secondary90` for the inactive track, and full rounding on track, handle, and stop indicators.
- Disabled styling is driven by neutral tokens and explicit opacity rows rather than separate disabled palette tokens for every surface, so the implementation should preserve both the base color and the opacity.
- Medium-and-up expressive sliders introduce inset icons through size-set tokens, but the measurements chart remains the source of truth for final preset dimensions when it conflicts with the token viewer.
- Because the measurements chart and token viewer disagree on the medium handle height and the label container height, geometry presets in this repository should prefer the charted measurement values and use the token viewer primarily for colors, states, and ancillary spacing.
