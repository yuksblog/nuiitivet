# Switch MD3 Specs

Source: <https://m3.material.io/components/switch/specs>
Collected: 2026-05-26

## Summary

- Switch exposes one active token set in the live viewer: `Switch` with `Default, Light` context chips.
- The component uses a 52dp by 32dp track with a 2dp outline, a 40dp state layer, and a 48dp minimum touch target.
- Handle sizes step between 16dp unselected, 24dp selected or with-icon, and 28dp pressed; enabled handle elevation is `md.sys.elevation.level1` and disabled handle elevation drops to `md.sys.elevation.level0`.
- Selected states pair `md.sys.color.primary` track or icon treatments with an `md.sys.color.on-primary` enabled handle and `md.sys.color.primary-container` hovered, focused, and pressed handle treatments.
- Unselected states keep the track and icon on `md.sys.color.surface-container-highest`, use `md.sys.color.outline` for track outlines, and switch to `md.sys.color.on-surface` for state-layer overlays.
- Focus adds a dedicated indicator on `md.sys.color.secondary` with a 3dp thickness and a 2dp offset.

## Implementation Notes

- Model the switch as a 52dp by 32dp track inside a 48dp target, with a 40dp circular state layer centered on the control.
- Size the handle by configuration and state rather than one fixed thumb size: 16dp unselected, 24dp selected or with-icon, and 28dp pressed.
- Keep selected track and selected icon treatments on `md.sys.color.primary`, pair the enabled selected handle with `md.sys.color.on-primary`, and move the selected hover, focus, and pressed handle fills to `md.sys.color.primary-container`.
- Keep unselected track and icon fills on `md.sys.color.surface-container-highest`, use `md.sys.color.outline` for unselected outlines, and use `md.sys.color.on-surface` for unselected hover, focus, and pressed state-layer overlays.
- Support the dedicated focus ring: `md.comp.switch.focus.indicator.*` maps to the MD3 focus-indicator system tokens with a 3dp thickness and 2dp outer offset.
- The viewer still exposes legacy handle shadow, size, and elevation tokens. Treat those rows as deprecated and prefer the selected, unselected, pressed, and with-icon token families for new implementation work.
