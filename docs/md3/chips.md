# Chips MD3 Specs

**Source:** <https://m3.material.io/components/chips/specs>  
**Collected:** 2026-04-30

## Summary

- The live MD3 token viewer exposes four non-deprecated chip token sets in the Default, Light context: Assist (51), Filter (107), Input (107), and Suggestion (51) for a total of 316 active component tokens.
- All four chip families share a 32dp container height and an 8dp container corner radius, with 18dp icons where icons are present.
- Filter and Input chips carry the largest state surface because they combine flat and elevated treatments with selected and unselected states; Assist and Suggestion are smaller token families with 51 rows each.
- Input chips add avatar geometry and close-icon affordances beyond the shared chip baseline, including a 24dp avatar, a 12dp avatar corner radius, and a minimum 48dp target for the close icon.

## Implementation Notes

- Model chips as four distinct component token families rather than trying to collapse them into one shared token namespace.
- Treat filter and input chips as the high-complexity variants: both expose flat and elevated treatments, selection state, and extra accessory tokens that do not exist on assist and suggestion chips.
- Shared measurements are stable enough to centralize in reusable layout constants: 32dp height, 8dp container radius, 18dp icon size, and 8dp inter-element padding.
- Input chip close affordances should preserve a minimum 48dp hit target even when the rendered trailing icon stays at 18dp.
