    Toolbars MD3 Specs¶

    Source: https://m3.material.io/components/toolbars/specs Collected: 2026-05-26

    Summary¶

    • The active toolbar viewer exposes five current token sets under the Default, Light context: Toolbar - Color - Standard, Toolbar - Color - Vibrant, Toolbar - Docked, Toolbar - Floating, and Toolbar - Floating - FAB.
    • The deprecated Bottom app bar (baseline) remains on the page in a separate viewer, but the spec explicitly marks it as not recommended and this document skips its token rows.
    • Docked toolbars are square 64dp containers with 16dp leading and trailing padding and 4dp to 32dp action spacing, while floating toolbars keep the same 64dp height with a full shape, 8dp internal side padding, 16dp horizontal edge margin, 24dp vertical edge margin, and 6dp elevation.
    • Standard color toolbars use md.sys.color.surface-container for the toolbar and unselected button container with selected buttons on md.sys.color.secondary-container; vibrant toolbars switch the base container to md.sys.color.primary-container and selected buttons back to md.sys.color.surface-container.
    • Floating toolbars with FAB add an 8dp gap between the toolbar and FAB, support 56dp and 80dp FAB sizes, use 24dp or 28dp FAB icons, and resolve their FAB corners and elevations from the MD3 large and large-increased shape tokens plus elevation levels 1 and 2.

    Implementation Notes¶

    • Treat toolbar geometry and toolbar color as separate concerns: Toolbar - Docked, Toolbar - Floating, and Toolbar - Floating - FAB define layout and shape, while the standard and vibrant color sets define the actual container and action colors.
    • Prefer docked and floating toolbars for new work. The spec page keeps the baseline bottom app bar only as a legacy fallback and explicitly recommends the docked toolbar instead.
    • Floating toolbars share the same standard-vs-vibrant color split as docked toolbars, but floating adds a 6dp elevated container and distinct horizontal vs vertical edge margins.
    • The floating FAB variant needs two FAB sizes in addition to the toolbar itself: 56dp with a 24dp icon and 16dp corner radius for the expanded FAB, and 80dp with a 28dp icon and 20dp corner radius for the medium FAB.
    • The extracted values here reflect the live Default, Light viewer context. Dark, contrast, and platform-specific variants remain available through the underlying contextual token tree but are intentionally out of scope for this document.
