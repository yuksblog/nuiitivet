    Date Pickers MD3 Specs¶

    Source: https://m3.material.io/components/date-pickers/specs Collected: 2026-03-12

    Summary¶

    • The primary token viewer exposes three non-deprecated token sets: Date picker - Docked, Date picker - Modal, and Date picker - Modal input.
    • Docked pickers use a 360dp x 456dp container with 48dp day cells, a 40dp month/year menu button height, and 48dp menu-list item height.
    • Modal pickers use a 360dp x 524dp container with 40dp day cells, 72dp x 36dp year chips, a 128dp range-selection header, and a 40dp in-range active indicator height.
    • Modal date input uses a narrower 328dp x 512dp container with a 328dp x 120dp header block.
    • Hover state-layer opacity is consistently 0.08; focus and pressed state-layer opacity are consistently 0.1 where exposed.
    • The Measurements sections expose figure captions in accessible text, but most numeric callouts are only available through the token viewer rather than the images themselves.

    Tokens & Specs¶

    Token sets discovered¶

    Token set Notes
    Date picker - Docked Context shown in viewer: Default, Light. States exposed: Enabled, Disabled, Hovered, Focused, Pressed (ripple).
    Date picker - Modal Context shown in viewer: Default, Light. States exposed: Enabled, Hovered, Focused, Pressed (ripple). Includes range-selection and year-selection tokens.
    Date picker - Modal input Context shown in viewer: Default, Light. Accessible viewer content exposes enabled-state tokens only.

    Implementation Notes¶

    • Treat docked and modal variants as separate layout systems. Docked uses 48dp dates and dropdown-menu affordances; modal uses 40dp dates, 72dp x 36dp year chips, and explicit range-selection geometry.
    • The type-style rows in the viewer are composite previews rather than directly useful scalar values. Use the accompanying font, size, line-height, weight, and tracking tokens for implementation.
    • Modal range selection adds distinct container and in-range tokens, including md.comp.date-picker.modal.range-selection.container.shape, md.comp.date-picker.modal.range-selection.active-indicator.container.color, and in-range state-layer colors.
    • Modal and modal-input surfaces both resolve their main container elevation through md.sys.elevation.level3; the modal range-selection container resolves through md.sys.elevation.level0.
    • The MD3 page currently exposes duplicated misspelled opcaity token/label variants for modal range-selection hover, focus, and pressed state-layer opacity. Preserve the canonical token names from the page if you need to mirror the source exactly.
