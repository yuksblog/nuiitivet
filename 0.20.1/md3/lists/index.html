    Lists MD3 Specs¶

    Source: https://m3.material.io/components/lists/specs Collected: 2026-05-25

    Summary¶

    • The live Lists token viewer exposes two UI-selectable token sets: List - Common and List - Expand, both shown in the Default, Light context.
    • List - Common carries the main implementation surface: enabled, selected, disabled, hover, focus, pressed, and dragged state colors plus shared spacing, shape, and typography tokens.
    • Core container heights are 56dp for one-line items, 72dp for two-line items, and 88dp for three-line items; expressive icon slots shrink to 20dp while baseline icon slots remain 24dp.
    • The baseline layout table adds concrete alignment constraints: 16dp leading padding, 24dp trailing padding, 48dp minimum targets, and 16dp/24dp divider insets.
    • The embedded payload also contains hidden List - Reveal and List - Reorder token-set records, but they are not selectable in the visible spec viewer, so this document follows the UI-visible sets only.

    Tokens & Specs¶

    Token sets discovered¶

    Token set Status Notes
    List - Common Active Visible selector option. Context shown in the viewer: Default, Light. Groups: Color, Spacing, Shape, Size and typography. The viewer also duplicates one-line/two-line/three-line heights under Color / Enabled with malformed token IDs; those duplicates are normalized to the canonical size rows below and omitted from the table.
    List - Expand Active Visible selector option. Context shown in the viewer: Default, Light. Groups: Color, Shape. Covers the expand interaction's collapsed and expanded trailing-icon treatment.

    Implementation Notes¶

    • Prefer the expressive list variant for new work; baseline remains available but the page explicitly recommends expressive lists for current designs.
    • Keep selected-state colors wired to secondary-container and on-secondary-container, while hover, focus, pressed, and dragged overlays come from the corresponding md.sys.state.* opacity tokens.
    • Treat list layout and list styling separately: the standard and segmented styles do not change behavior, but segmented lists add a 2dp gap and rounded expressive shapes.
    • Preserve the baseline alignment contract for mixed-content rows: 16dp leading padding, 24dp trailing padding, and at least 48x48dp interactive targets.
    • Model the expand interaction as a separate style surface: it uses its own trailing-icon container colors and a fully rounded trailing-icon shape on top of the large rounded expand container.
    • Ignore the payload-only List - Reveal and List - Reorder token sets unless the MD3 spec starts exposing them in the visible selector or the user asks for those hidden sets explicitly.
